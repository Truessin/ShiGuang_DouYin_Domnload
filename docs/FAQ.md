# 常见问题

## 启动相关

### 双击 EXE 没反应 / 提示缺少 DLL

请确认 `_internal` 文件夹与 `Shiguang.exe` 位于同一目录，并且是完整解压后的状态，而不是在压缩包预览窗口中直接运行。若仍失败，请尝试从源码运行以查看具体错误信息。

### 提示“没有找到 Edge 或 Chrome”

程序复用本机浏览器，不会额外下载浏览器内核。请安装 [Microsoft Edge](https://www.microsoft.com/edge) 或 [Google Chrome](https://www.google.com/chrome/)，然后重新启动程序。

### 程序无法保存文件

请确认程序所在目录可写。若放在 `C:\Program Files` 等受保护目录，请移动到用户目录（如桌面或 `D:\Tools`），或在界面中选择其他保存位置。

## 解析与下载

### 提示“未读到该作品完整媒体清单”

常见原因：

1. 作品需要登录或人机验证 —— 点击“登录 / 验证”，在专用浏览器中完成后再试。
2. 链接是主页、直播或合集 —— 请使用单个作品链接。
3. 作品已删除、仅粉丝可见或地区受限。
4. 页面结构发生变化 —— 请更新到最新版本，或提交 Issue 并附上错误提示。

也可以勾选“解析时显示浏览器”，观察页面实际打开情况。

### 提示“第 N 张图片未提供可用的无平台水印地址”

该作品页面只返回了带平台水印的图片地址。程序不会用带水印版本替代，也不会涂抹处理，因此停止下载。这属于作品的源数据限制，不是程序故障。

### 为什么保存的图片不是 JPG？

程序按服务器返回的真实文件头保存，可能得到 WebP、AVIF、HEIC 等格式，这样能避免二次转码造成的画质损失。大多数看图软件与浏览器都支持这些格式。

### 为什么图集数量和抖音上看到的不一样？

程序只接受与作品编号严格匹配的图片清单，不会把头像、封面、推荐作品或页面广告算进去。如果页面本身提供的清单不完整，程序可能报错而不是输出残缺图集。请先确认在专用浏览器中也只看到相同数量的图片。

### 视频不是最高画质？

程序只能从页面公开提供的格式中选择。若平台对未登录用户只提供较低清晰度，登录后重试可能获得更高版本；平台已压缩的内容无法还原。

### 下载到一半失败

程序会清理未完成的 `.part` 文件，已成功的文件保留。重新粘贴链接下载即可；同名文件不会覆盖，而是添加序号。当前版本不支持跨次断点续传。

### 为什么文件名后面出现 `_2`？

同一作品重复下载时，为避免覆盖已有文件，程序自动添加序号。可以手动整理 `downloads` 目录。

### 点击“停止”后没有立即结束

程序会等待当前网络连接返回，并关闭专用浏览器，通常只需几秒。若长时间无响应，可关闭程序后重新启动；未完成的 `.part` 不会被计为成功。

## 安全与合规

### 会上传我的登录信息吗？

不会。登录状态只保存在本机 `data/browser-profile`，不写入作品信息，也不发送到第三方解析服务。详见 [隐私与安全](PRIVACY.md)。

### 可以去水印吗？

本工具**不提供去水印功能**。它只选择页面中本身不带平台水印的图片源；作者在源图中自带的文字、署名或水印会保留。程序不裁切、不涂抹、不重编码。

### 可以下载别人的作品吗？

请只下载你本人创作或已获得权利人许可的内容，并遵守平台条款与当地法律。项目不提供批量抓取、绕过访问控制或规避付费的功能。

## 开发相关

### 测试时窗口不显示

界面测试默认使用 `QT_QPA_PLATFORM=offscreen`，不会弹窗，这是预期行为。

### 支持 macOS / Linux 吗？

当前仅针对 Windows 打包与测试。`core.py` 的解析逻辑是跨平台的，但 `browser.py` 的浏览器定位与打包脚本面向 Windows；欢迎提交跨平台适配。
