# 使用说明

本文面向直接使用发布包的用户。开发、构建与测试见 [开发文档](DEVELOPMENT.md)。

## 1. 安装与启动

1. 从 [Releases](https://github.com/Truessin/shiguang-downloader/releases) 下载 `Shiguang-v*-win64.zip`。
2. 解压到任意**可写**目录。不要只把 `Shiguang.exe` 单独移出，`_internal` 必须与 EXE 位于同一目录。
3. 双击 `Shiguang.exe`。

首次启动会在程序目录创建 `data` 与 `downloads` 文件夹。若程序位于 `C:\Program Files` 等受保护目录，可能无法写入，请移动到用户目录后再运行。

从源码运行的步骤：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

需要 Python 3.11+ 与 Microsoft Edge 或 Google Chrome。

## 2. 下载一个作品

1. 在抖音中打开目标作品，点击“分享 → 复制链接”。
2. 把复制到的**整段文字**粘贴到输入框，不需要手动删除文案。
3. 点击“开始下载”。
4. 完成后点击“打开文件夹”，或双击列表中的文件直接打开。

支持一次粘贴多个作品链接，程序会逐个处理并在列表中展示每个文件的状态。

### 支持的内容

| 内容 | 支持情况 |
| --- | --- |
| 单个视频作品 | 支持，选择页面提供的最高分辨率 / 码率 |
| 单张图片作品 | 支持 |
| 多图图集 | 支持，保存全部图片并保持原顺序 |
| 多个作品链接 | 支持，逐个处理 |
| 主页全部作品、直播、私密 / 付费内容 | 不支持 |

### 链接格式

以下格式均可识别：

```text
https://v.douyin.com/xxxxxxx/
https://www.douyin.com/video/7123456789012345678
https://www.douyin.com/note/7123456789012345678
https://www.iesdouyin.com/share/video/7123456789012345678/
```

包含上述链接的整段分享文字也可以直接粘贴。

## 3. 保存位置与文件名

默认保存到程序目录的 `downloads`。点击“选择文件夹”可更改统一保存位置，设置会写入 `data/settings.json`，下次启动继续生效。

每个作品单独一个文件夹，命名为 `作品编号_标题`：

```text
downloads/
└── 7690457558616945051_庆幸带了胶片.../
    ├── 001.webp
    ├── 002.webp
    ├── ...
    ├── 视频.mp4             # 视频作品
    └── 作品信息.json
```

- 图集按页面原始顺序编号；扩展名来自实际文件头，可能是 `.jpg`、`.png`、`.webp`、`.avif`、`.heic`。
- 视频保存为 `.mp4` 或 `.webm`。
- 重复下载不会覆盖已有文件，而是保存为 `001_2.webp` 等。
- `作品信息.json` 记录文件大小、尺寸与 SHA-256，可用来核对文件完整性。

## 4. 登录与验证

部分作品需要登录或完成人机验证。此时：

1. 点击“登录 / 验证”。
2. 程序打开一个独立的浏览器窗口（本机 Edge 或 Chrome）。
3. 在窗口中正常登录或完成验证。
4. **关闭该浏览器窗口**，回到程序，再点击“开始下载”。

也可以勾选“解析时显示浏览器”，让解析过程直接显示在专用浏览器中，便于在作品页完成验证。

登录状态保存在本机 `data/browser-profile`，不会写入导出的作品信息，也不会上传到任何第三方服务。**不要把 `data` 文件夹分享给他人。**

## 5. 进度、停止与失败处理

- 顶部进度条表示整批作品的处理进度；单行进度条表示该文件的下载进度。
- 解析阶段进度条滚动，表示正在读取页面，不虚构百分比。
- 文件大小未知时同样显示滚动状态，只显示已接收字节数。
- 点击“停止”后，程序等待当前连接返回并关闭专用浏览器；已完成文件保留，未完成的 `.part` 文件会被清理。
- 某个作品失败时会明确标记“未完成”，其余作品可以继续处理。可重新粘贴链接重试；已存在文件会另存。

## 6. 关于画质与“无水印”

- 视频：在页面提供的格式中优先选择最高分辨率，同分辨率下选择更高码率。
- 图片：优先使用页面实际提供的原图 / 展示源地址，并排除已知的平台水印模板（如 `tplv-dy-water-v2`）。
- `download_url_list` 等字段常带平台水印，不能仅凭字段名认定为原图。
- 如果只找到带平台水印的地址，程序会报错停止，不会静默下载带水印版本。
- 程序不裁切、不涂抹、不缩放、不重编码、不额外压缩。
- 作者在源图中自带的文字、署名或水印不会被去除。

平台已经压缩过的内容无法还原为上传前的源文件；不同作品提供的清晰度与格式可能不同。本工具不保证获取平台未公开的原始文件。

## 7. 文件与隐私

| 路径 | 内容 | 是否可分享 |
| --- | --- | --- |
| `downloads/` | 下载的作品与 `作品信息.json` | 由你决定（注意他人著作权） |
| `data/settings.json` | 保存目录设置 | 不建议 |
| `data/browser-profile/` | 专用浏览器资料与登录状态 | **绝对不要分享** |

程序不读取你日常浏览器的账号或密码，不复制旧程序的 Cookie、调试响应或历史记录。详见 [隐私与安全](PRIVACY.md)。

## 8. 卸载

本程序为绿色版，直接删除程序文件夹即可。删除前请先备份 `downloads` 中需要保留的作品。
